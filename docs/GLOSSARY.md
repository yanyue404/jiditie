# 挤上3号线

广州地铁 3 号线早高峰主题的网页挤地铁游戏。本 glossary 记录产品与统计领域的共享语言。

## Language（语言）

**氛围灯**：
展示给玩家看的全站聚合数字，只做社交证明与共鸣，不改变关卡物理或胜负规则。
_Avoid_：旁观者后台、共建世界、联机玩法

**通勤者**：
一台浏览器上的匿名设备身份（`localStorage` UUID），用于去重「唯一访客」，不是账号。
_Avoid_：用户、账号、玩家档案、昵称排行

**门厅指标**：
进入站点相关的聚合：进页次数、唯一通勤者、今日活跃。
_Avoid_：PV/UV（对外文案）、session、在线人数

**车厢指标**：
对局结果相关的聚合：成功挤上、失败落车、扒拉次数、文明通关。
_Avoid_：个人存档 stats（仍只存在本地 `line3-save`）

**D1 账本**：
用 Cloudflare D1 持久化的全站计数存储；第一版无 Durable Object、无 WebSocket 实时推送。
_Avoid_：实时在线、全球数字狂跳、双写 DO+D1

**进页**：
一次完整文档加载计 1 次；SPA 内从结算返回线路图不计。
_Avoid_：路由跳转、软刷新、页面可见性变化

**今日活跃**：
每个日历日（UTC+8）每个通勤者最多计 1 次。
_Avoid_：session、在线、同时打开的标签数

**计数器行**：
D1 只存聚合整数（全局一行 + 按日一行），不存事件流水。
_Avoid_：事件日志、可重放审计、按站热度（第二期）

**静默降级**：
统计 API 不可用时玩法与本地存档照常；氛围灯数字隐藏或显示占位，不弹错。
_Avoid_：阻断开局、强制重试弹窗

**本局增量**：
结算时上报的车厢字段（胜/负 0|1、本局扒拉次数、文明通关 0|1），由服务端累加进计数器行；不是本地累计绝对值覆盖。
_Avoid_：绝对值同步、排行榜分数
